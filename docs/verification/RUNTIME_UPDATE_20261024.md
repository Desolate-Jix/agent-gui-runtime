[发布记录](../releases/EXECUTION_018_20261024.md)。下文“合成 0.1.8”仅指早期测试夹具，

## 明确边界

- `0.1.8` 是测试合成版本，不是发布物。当前公开 0.1.7 不含更新器，首次迁移仍须
  手动安装，并由操作员先结束、核实旧 stdio／HTTP／管理员入口、外部 Python 宿主
  及模型 worker。新锁不能证明未加入协议的旧进程已退出。
- 下载测试使用固定 GitHub URL 的合成传输，不访问真实发行下载服务；本轮没有
  发布更新元数据／资产，也没有进行真实线上更新、物理断电或新机器安装认证。
- 中断检查是进程退出模拟，不是物理断电测试；Windows 文件／日志原子替换使用
  write-through。回滚失败保留备份并阻止启动，不宣称所有存储故障都可自动恢复。
- 安装模式测试使用当前用户 TEMP 中的独立测试根，不写日常快捷方式或卸载注册表；
  注册版本失败／恢复用隔离后端测试，不代表改动过用户的真实 HKCU 产品记录。
- 健康检查是无输入导入／合同核验，不是新版本的 GUI 成功率或模型准确率测试。
  安装器仍未签名，固定 HTTPS 来源与 SHA-256 不构成独立发布者签名。
- 回滚覆盖受管程序文件和安装版本，不清空用户数据、密钥、模型或环境，不重放
  原任务。依赖／Python 合同／随包配置变化走手动迁移。
- Amadeus 上游改动与其额外生命周期门禁，另见
  [独立实现记录](../development/AMADEUS_UPDATE_IMPLEMENTATION.md)，不能由 Runtime
  的安装测试推定其已在用户安装中生效。

使用入口与恢复命令见[中文更新说明](../RUNTIME_UPDATES.zh-CN.md)。
