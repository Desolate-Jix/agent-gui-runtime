## Scope / 范围

One caller submission should run a bounded linear plan through the existing queue, local grounding, gated input, outcome verification and next-step scheduling. Learning installation and old learning assets are unnecessary. Main must not need to forward screenshots or issue a continuation for each healthy step. Genuine uncertainty retains the original evidence and waits. / 一次提交后由原运行器完成可靠步骤，学习安装可选；健康步骤无需 Main 逐图转发或逐步继续，不确定时保留原证据。

Ordinary Luna image grounding was a separate, bounded API evaluation and has ended. Local grounding remains the selected acceptance route; Decision is optional outcome verification. See [external vision results](../development/EXTERNAL_VISION_BENCHMARK.md). / 普通 Luna 识图评估已结束，后续使用本地定位，Decision 可选核验。

## Failure records / 故障记录

### F1: Pending-status client failure / 客户端等待故障

1. **Failure / 现象:** The first action occurred, but `run_plan` raised on a rejected queued status control and closed the host before full-plan completion. / 首步已发生，查询被拒后客户端提前退出。
2. **Invariant / 合同:** Healthy observation must not compete with the active input owner or replay the original command. / 健康状态观察不能竞争输入队列或重派。
3. **Fix location / 位置:** `scripts/learning_benchmark_client.py`; poll `instant_status.task_plan_run`, preserving the original start receipt and request/run identities. / 改为只读投影，保留原身份。
4. **Cross-app reason / 通用性:** This queue conflict applies to any pending application action, independent of the target app. / 所有应用的 pending 动作均适用。
5. **Regression / 回归:** Real attachment-transport admission reproduction, shared TaskPlanRuntime two-step offline integration and client/configuration checks: 80 passed. Live root03 completed through one start, 128 read-only polls and no recorded callback; both original execution IDs match the correct independent oracle order. / 离线回归及完整实机复测通过，128 次轮询不是 128 次模型调用。
6. **Safety / 安全:** No admission gate weakened. Explicit controls can still be rejected; timeout never cancels or resubmits automatically. / 不放宽门禁，不自动取消或重发。

### F2: Browser field hit and ownership / 浏览器字段命中及归属

1. **Failure / 现象:** Visible Search field refused before input; initial hit can be a large mixed-readonly Document. Later exact ComboBox hits fail the window/process guard. / 可见搜索框在输入前拒绝，粗命中和归属失败均已记录。
2. **Invariant / 合同:** A field must have a current writable identity inside the bound native window; a screenshot location alone is insufficient. / 必须证明当前可写字段与绑定窗口归属。
3. **Fix location / 位置:** `windows_text_field_reader.py`: bounded 32-level same-PID ancestry with cycle checks and native-root validation; bounded read-only readiness only for initially coarse point hits. / 公共字段层改为最多 32 层同进程归属、循环及原生根检查；初次粗命中允许有界只读就绪采样。
4. **Cross-app reason / 通用性:** All 18 observed nodes retain the same PID and the final Win32 root matches the selected window, excluding a renderer-PID mismatch in this reproduction. Early point samples resolve a coarse container before converging; bounded read-only readiness must still return a proven exact writable field. / 本次排除跨 renderer PID，公共修复面向深层虚拟控件及初次粗命中，仍须精确可写证明。
5. **Regression / 回归:** Field/focus/diagnostic batch: 173 passed; input/binding/keyboard batch: 86 passed (overlapping coverage, not summed). The fresh browser rerun passed this pre-click boundary, then exposed a distinct focused-identity failure before typing. / 两批离线回归通过；实机已越过原归属故障，但填写前的聚焦身份仍失败，整项未通过。
6. **Safety / 安全:** No writable-descendant substitution, blind typing, profile changes or native Codex Computer Use. Browser windows created by these probes were closed through the maintained interface. / 不替换后代或盲输，不改浏览器配置，测试窗口正常关闭。
