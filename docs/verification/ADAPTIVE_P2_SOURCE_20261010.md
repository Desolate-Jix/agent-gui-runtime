## Reviewed defects / 审阅缺陷

1. **Final cancellation gate:** a cancel queued during backend authentication could still settle an ordinary, non-observation Decision as success. The final gate now covers every new settlement, preserving the original ticket and input fact. Read-only replay of already settled results stays idempotent. / 最终取消门禁扩展至全部新结算，保留已发生输入及原票据；已结算结果的只读回放保持幂等。
2. **Learning graph context:** definition order is not execution order. The context now follows the current success edge, describes reachable success/failure edges explicitly and emits shared nodes once. Dynamic values remain excluded. Changed v2 projections require fresh runs; old authenticated contexts are not recomputed as new evidence. / 学习上下文按实际后继图生成，不按列表位置截取；保留脱敏，升级后的多步骤 v2 应用新运行验证。
3. **Total HTTP deadline:** owned transport now reuses one async pool/loop behind the synchronous provider, cancelling the single request at its monotonic network deadline. The service also rejects answers after the remaining assessment budget expires. Dispatch markers prevent automatic repeat billing. Requests explicitly accept identity encoding; encoded bodies are rejected before reading to prevent decompression expansion beyond the 64 KiB bound. This is not a hard real-time deadline for native capture, TLS initialization or local persistence. / 自有传输以单调截止限制整个网络请求，服务再次拒绝迟到结果；不重派，压缩体在读取前拒绝。该合同不等于截图、冷初始化或本地落盘的硬实时截止。

An explicit enabled v2 `always_main` profile applies in both auto and shadow mode; this is configured policy, not a model suggestion. An off service does not change complete local proofs. Step-level explicit review still tightens the contract. Main reproduced learning's shadow-policy omission (1 failed/5 passed) and repaired it (6 passed); execution is aligned. / 显式启用的全局逐步审核在auto/shadow均生效，off不改变完整本地证明；单步明确审核仍收紧策略。Main以六组合复现并修复学习端遗漏，执行端保持同义。

The third defect was reproduced with a loopback HTTP server continuously sending small chunks, without external network inference. Its initial two tests failed as expected. The first wall-time assertion included cold TLS initialization; that failed assertion is retained, and the final test explicitly warms the owned client before testing slow chunks, then verifies another request and normal close. / 第三项以本机慢分块复现；首次两失败保留。首次时长断言混入 TLS 冷初始化也保留，最终测试明确预热后验证超时、复用及关闭。

Independent transport review identified the compressed-body issue; Main repaired it and the reviewer statically confirmed both the rejection and timeout/reuse/cleanup coverage. / 独立审阅发现压缩扩张，Main 修复后审阅者只读确认修复与回归覆盖。

## Native semantic continuation / 原生语义续接

V1 stays unchanged. V2 `native_condition` may explicitly declare `decision_condition`, `allowed_states`, `review_policy` and `wait_policy`, reusing the strict `agent_judgment` options. The other controls require an explicit decision condition. A complete local proof uses zero API calls; explicit step `always_main`, or an enabled v2 global `always_main` in auto/shadow, pauses without a preliminary call. Global off preserves local success. / v1不变；v2原生条件可显式声明同样严格的判断/状态/审核/等待选项，其他控制项不得脱离decision_condition生效。完整本地证明零调用；单步明确逐步审核或已启用v2全局auto/shadow逐步审核直接暂停，global off保留本地成功。

Only completed original input, the same window birth identity and the verified original after image can proceed. The helper requires the maintained `timed_out` proof and observation markers, matching source/expected/hash, every baseline/sample legally absent or matched, finite monotonic sample times, valid integer runtime IDs and bboxes within the original PNG. Ambiguous, unavailable, error, unknown, malformed or mismatched evidence goes to review without paying. Input sequences use their bound final search receipt. / 仅可信原输入completed、同窗出生身份和已核验原after可以接续；维护超时证明及外层标记、source/expected/hash、全部合法absent/matched记录、有限单调样本时间、整数runtime_id及原PNG内bbox均须有效；歧义、不可用、错误、未知或损坏证据不付费绕过。组合输入绑定末次search原件。

`after_capture_rechecked=False` remains false and the original receipt is never rewritten. Semantic evaluation reuses the original after image through the existing Decision/finite-observation path, retaining profile, allowlist, budget, ownership and cancellation gates. Backend independently rechecks native eligibility before adopting a Decision. The maintained collector can capture an early stable match, see it disappear on recheck and later time out; validate total elapsed≥timeout and cumulative capture≤elapsed rather than subtracting every earlier capture from the deadline. / 不把原False补写为True，也不改原票据；共用判断及有限观察保留全部门禁，最终backend再次重核资格。早期命中截图后复查消失再超时属于合法维护路径；时间校验不误扣截止前已有截图耗时。

The bounded independent read-only review reported no specific P1/P2 in its scope. This is source review, not new-candidate desktop acceptance or full-release readiness. / 限定独立只读审阅无明确P1/P2，仅代表所审源码范围，不替代新候选实机或完整发布验收。
