## English

0.1.10 addresses two maintenance failures reported during connector review.
Rejected task-plan controls can settle when an original durable proof establishes
that the request did not reach input dispatch or grant further input capability.
An error message or a missing admission record is not that proof. Interrupted,
incomplete or inconsistent processing remains blocked, as does unknown input.

Read-only `observe` can also settle through its original request, observation
record, image and revised review packet. The original task's input receipts
must still independently reach terminal settlement. Reading a new image does
not verify business success, approve a click or continue a task.

The release does not add settlement support for `recover` or
`resume_pre_dispatch`. Those task-plan controls remain conservatively
unqualified; they differ from the operator-only session recovery tools.
No model/provider default, threshold or input authorization is changed.

Use the [external-verifier procedure](../RUNTIME_018_SETTLEMENT_RECOVERY.md)
before upgrading an affected installation. Valid older plan/observation evidence
can be rechecked; old rejected requests without sufficient original proof may
still block maintenance. Do not delete registrations, rewrite evidence or
replay a task to obtain a passing state. Recovery of every old session is not
guaranteed.

Connector 0.0.7 updates the packaged recommendation to this Runtime. Its settings,
permissions and operator-only disconnected recovery boundary are unchanged;
same-session Main screenshot review and explicit continuation remain available.
The recommended combination and minimum protocol capability are separate:
successful initialization or a later patch number does not certify a new
combination. [PR #11](https://github.com/Code-Amadeus/Amadeus-Extensions/pull/11)
retains maintainer-owned independent acceptance and catalog publication.

Exact regressions, interruption/negative cases, package and installed workflow
results are recorded in the release validation attachments. Earlier unchanged
results retain their original scope; this is not a new GUI performance or
general-accuracy benchmark. Published hashes identify the tested assets, but
GitHub-enforced release immutability is not claimed. The installer is unsigned.

## 简体中文

0.1.10 修复连接器审核中报告的两类维护失败。被拒绝的任务计划控制请求，只有
原始持久证明能确认其未进入输入派发、也未授予后续输入能力时才可结算。
错误文字或准入记录缺失本身不是证明；中断、写入不完整、不一致及未知输入仍拒绝。

只读 `observe` 则通过原请求、观察记录、截图及更新后的审核 packet 核验结算。
原任务的输入回执仍需独立终结。读取新图不代表业务成功，不批准点击，也不自动
继续任务。

本次不增加 `recover`、`resume_pre_dispatch` 的结算支持；这两类任务计划控制
仍保守拒绝认证，与操作员使用的会话恢复工具不同。不改模型／服务商默认值、
阈值或输入授权。

受影响的安装可先按[独立新版核验器流程](../RUNTIME_018_SETTLEMENT_RECOVERY.md)
处理，再正常确认升级。原计划／观察证据充分的旧会话可重新核验；缺少足够原始
证明的旧拒绝请求仍可能阻止维护。不要删除登记、改写证据或重做任务来获得通过，
也不保证所有旧会话以后都能恢复。

连接器 0.0.7 将包内推荐更新至本版，设置、权限、断线恢复交操作员的边界不变，
同会话 Main 看图审核后明确继续原任务的能力保留。推荐组合和最低协议能力分别
说明；初始化成功或补丁版本更高不等于新组合已认证。维护者仍在
[PR #11](https://github.com/Code-Amadeus/Amadeus-Extensions/pull/11)负责独立验收与商店发布。

具体回归、中断／负控、安装包和安装态任务结果见发行验证附件。旧结果按原范围
保留，不新增 GUI 性能或通用准确率结论。摘要标识已测资产，不宣称 GitHub 已强制
发行不可变；安装器仍未签名。
