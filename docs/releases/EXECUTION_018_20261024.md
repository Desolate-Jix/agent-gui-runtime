## English

**0.1.8 is the first updater-enabled Runtime. Install it manually after closing
0.1.7 or any older installation.** Old versions cannot upgrade themselves or
prove that their untracked external-Python hosts have exited. Close and check
all old stdio/HTTP/admin clients, hosts and model workers before migrating.

Launchers check this project's stable GitHub releases in the background, at
most once daily; checks can be disabled. They do not install, download a payload
or invoke model APIs. `instant_status` exposes a short cached summary.

Use `scripts/update_runtime.ps1 -Action stage` to download and verify the exact
target, then `-Action apply` to review and confirm its SHA-256. Installation-wide
shared/exclusive locks cover maintained clients, MCP transports, child hosts,
model workers and setup/installer paths. Persistent session registrations keep
unknown input and unverified cleanup blocked even after a process crashes.
The updater does not kill a task, replay input or restart an old task to update.

Before replacing owned source files, the updater verifies the existing
uninstaller's embedded manifest and keeps backups plus a persistent journal.
The new payload, uninstaller and ownership record change together. A fixed,
isolated health check receives no inherited provider/MCP/profile credentials
and creates no input host. Installation or health failure attempts rollback;
interruption has an external old-code recovery entry. Unsafe or incomplete
rollback retains backups and prevents new execution until resolved. User data,
model weights, secrets and Python environments are not cleared or rolled back.

This implementation supports compatible patches on the same major/minor line.
Dependency/Python-contract, shipped configuration or release-line changes
require manual compatibility review and migration. Source and hashes are pinned
to the project's HTTPS releases; the installer remains **unsigned**, and hashes
are not an independent publisher signature. Physical power-loss recovery and
clean-machine dependency installation were not newly certified.

### Amadeus remains independent

The resource-only HTTP MCP + Skill wheel remains **0.0.4**, at its unchanged
[0.1.6 download](https://github.com/Desolate-Jix/agent-gui-runtime/releases/tag/instant-v0.1.6).
No unchanged wheel is republished for a compatible Runtime patch. Host-side
optional daily checks, exact-version startup scheduling, native confirmation
and extension rollback are submitted separately in [Amadeus PR #261](https://github.com/Code-Amadeus/Amadeus/pull/261).
They require upstream merge and a new Amadeus build; installing Runtime 0.1.8
does not install those Host changes. That implementation includes Windows
process-tree cleanup proof and preserves previous package/config/encrypted
secrets, while unknown cleanup blocks updates and rollback.

### Validation and limits

The development regression group passed **502 tests** on Python 3.12 with two
skips; the external Amadeus Python HTTP case was separately enabled and passed.
Subsequent affected checks, complete temporary-install/update/rollback/crash
recovery/uninstall tests and real no-input stdio-host checks passed; overlapping
groups are not added. Release-version/package checks and exact final hashes are
in the package-verification asset. Synthetic future versions in tests are not
additional releases. No new GUI speed, accuracy or token-saving claim is made.

Amadeus's earlier complete npm run passed **637 tests**; later cleanup-index
compaction passed **19 affected Node tests**, including two real Windows
self-created-process cases; **48 Python cleanup/provider tests**, TypeScript
and the application build passed. These results are scoped source evidence,
not acceptance of an installed Amadeus build or a physical power failure.

## 简体中文

**0.1.8 是首个包含更新器的 Runtime，0.1.7 及更早安装须先关闭再手动安装本版。**
旧版不能自行升级，也不能证明未参与新协议的外部 Python 宿主已退出。首次迁移前须
关闭并核实旧 stdio／HTTP／管理员客户端、宿主及模型 worker。

启动入口在后台检查本项目 GitHub 稳定版，每天最多一次，可关闭；检查不安装、
不下载程序载荷、不调用模型 API。`instant_status` 只报告简短的缓存更新状态。

通过 `scripts/update_runtime.ps1 -Action stage` 下载核验确切目标，再用
`-Action apply` 审阅并确认其 SHA-256。安装级共享／排他锁覆盖维护中的客户端、
MCP 入口、子宿主、模型 worker 及配置／安装入口。持久会话登记使崩溃后的未知输入
和未验证清理仍被阻止。更新器不会为了升级而杀任务、重放输入或重启旧任务。

替换受管源码前，核对旧卸载器的内嵌冻结清单，保留备份和持久日志；新载荷、卸载器
及所有权记录一起切换。固定的隔离健康检查不继承模型／MCP／profile 凭证，不创建
输入宿主。安装或健康检查失败时尝试回滚；中断提供运行外部旧代码的恢复入口。
回滚不安全或未完成时保留备份，并阻止新执行直至处理。用户数据、模型权重、密钥
和 Python 环境不被清空，也不随代码回滚。

第一版支持同 major/minor 发行线内的兼容补丁。依赖／Python 合同、随包配置或
发行线变化，须先核对兼容性并手动迁移。下载固定为本项目 HTTPS 发布来源并核对
摘要；安装器仍**未签名**，摘要不是独立发布者签名。本轮未新增物理断电恢复或
全新机器依赖安装认证。

### Amadeus 仍分别升级

资源型 HTTP MCP＋Skill wheel 保持 **0.0.4**，保留原字节及
[0.1.6 下载地址](https://github.com/Desolate-Jix/agent-gui-runtime/releases/tag/instant-v0.1.6)。
兼容的 Runtime 补丁不重发未变化的 wheel。Host 侧可选每日检查、确切版本启动时
排队、原生确认及扩展回滚，已单独提交 [Amadeus PR #261](https://github.com/Code-Amadeus/Amadeus/pull/261)。
需要上游合入并构建新 Amadeus 才能生效，安装 Runtime 0.1.8 不会安装这些 Host
改动。该实现包含 Windows 子进程退出证明，保留旧包／配置／加密密钥；清理未知时
更新和回滚都会被阻止。
