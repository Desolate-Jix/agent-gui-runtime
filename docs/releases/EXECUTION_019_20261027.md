## English

0.1.9 fixes maintenance settlement for task plans. In 0.1.8, a completed plan
could leave an installation registration that the official updater could not
settle, even after normal process cleanup. The repaired verifier binds the
original plan and runner to command, input and terminal evidence. Completed and
proven-cancelled plans can settle; active or unknown input and missing or
inconsistent evidence remain blocked. No registration is removed merely because
a process exited or a plan says “completed”.

Affected 0.1.8 installations can use the new release's verified maintenance
script against the old installation, then use the normal confirmed update path.
See the [recovery procedure](../RUNTIME_018_SETTLEMENT_RECOVERY.md). Do not delete
registrations or bypass cleanup and input proofs. Old published artifacts stay
unchanged; Runtime settings, provider defaults and model thresholds are not
changed by this release.

The separately versioned Amadeus connector 0.0.6 recommends the repaired Runtime.
Its configuration keys, permissions and recovery boundary stay unchanged:
same-session Main screenshot review and explicit continuation remain supported;
disconnected or unresolved-owner recovery stays with the operator. Mutable
store-review status is kept in the PR/release rather than packaged Skill text.
Publication of this wheel is not store approval; maintainers still own final
independent acceptance and catalog publication in [PR #11](https://github.com/Code-Amadeus/Amadeus-Extensions/pull/11).

Exact regression, immutable-package, upgrade and installed Pi/HTTP/Runtime
results and limits are recorded in the release's validation attachments. Old
failure evidence is retained. This maintenance fix makes no new GUI speed,
accuracy or token-saving claim. The Windows installer remains unsigned.

## 简体中文

0.1.9 修复任务计划的维护结算。0.1.8 可能在计划完成、进程正常清理后，仍留下
官方更新器无法结算的安装登记。新版将原计划和 runner 与命令、输入及终态
证据绑定验证。已完成、已证明取消的计划可结算；活动／未知输入、证据缺失或
不一致仍拒绝。不会只凭进程退出或计划写着“完成”就删除登记。

受影响的 0.1.8 安装可先用独立核验的新发行维护脚本检查旧安装，再走正常的
确认更新流程，见[恢复步骤](../RUNTIME_018_SETTLEMENT_RECOVERY.md)。不删除登记，
不绕过清理和输入证明。旧发布产物保持原字节；本次不改 Runtime 设置、服务商
默认配置或模型阈值。

独立版本的 Amadeus 连接器 0.0.6 更新推荐 Runtime，配置键、权限和恢复边界
不变：保留同会话 Main 看图审核后明确继续原任务；断线或 owner 未解决时仍交
操作员处理。易变商店审核状态放在 PR／Release，不再写入包内 Skill。
发布 wheel 不代表商店批准；维护者仍在 [PR #11](https://github.com/Code-Amadeus/Amadeus-Extensions/pull/11)
负责最终独立验收与收录发布。

确切回归、不可变安装包、升级路径及安装态 Pi／HTTP／Runtime 的结果与限制，
见发布附件中的验证报告。原失败证据保留。本次维护修复不新增 GUI 速度、
准确率或 token 节省结论；Windows 安装器仍未签名。
