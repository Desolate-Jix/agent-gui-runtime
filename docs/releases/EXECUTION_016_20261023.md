# Runtime 0.1.6 / Amadeus extension 0.0.4

2026-10-23 · [Release and SHA-256 checksums](https://github.com/Desolate-Jix/agent-gui-runtime/releases/tag/instant-v0.1.6) · [English setup](../../integrations/amadeus/agent-review-instant/README.md) · [中文安装](../../integrations/amadeus/agent-review-instant/README.zh-CN.md)

## English

Runtime 0.1.6 adds an authenticated, loopback-only Streamable HTTP MCP service alongside the existing stdio entry point. Amadeus extension 0.0.4 supplies the native HTTP connection and execution Skill. Install and start Runtime separately, then import the wheel, configure its local URL and separate connection token, bind MCP + Skill to Pi, enable and restart the backend, and create a new Work.

When Decision and ordinary Luna both reject a candidate before input, the original Main can read its bound **before** image, explicitly review it, then separately continue the same run/step/job/attempt and candidate. Review alone does not click; continuation takes a fresh screenshot and retains window identity, target, geometry, visibility, freshness, cancellation and input checks. Completed input is not replayed. Existing settled-text review still uses the bound **after** image.

Temporary command-queue lock contention now waits briefly and rechecks the original continuation conditions instead of becoming a permanent task-binding failure. Cancellation is still a rejection. The original deadline and short post-capture dispatch lease are not extended. Decision/Luna thresholds, prompts and provider defaults are unchanged.

New API/Agent environments default to Python 3.12; supported existing Python 3.11 environments can be retained. Runtime and Amadeus use separate virtual environments and dependency locks. The optional local-model route remains Python 3.11; the historical root `pyproject.toml` describes that older local/source dependency contract, not the independent API setup. API vision does not need local model weights or a GPU. Provider endpoints, models and key environment variables remain separately configurable; the extension receives only its local MCP connection token.

The execution-only maintenance history is also included: learning entry points are retired and archived, while shared execution modules and input gates remain. This does not release a new learning version. [Archive boundary](../LEARNING_PAUSED.md).

## 简体中文

Runtime 0.1.6 保留 stdio，新增仅绑定本机、带鉴权的 Streamable HTTP MCP。Amadeus 扩展 0.0.4 提供原生 HTTP 连接声明与执行 Skill。先单独安装、启动 Runtime，再导入 wheel，填写本机地址与独立连接 token，将 MCP＋Skill 绑定 Pi，启用并重启后端，然后新建 Work。

点击前 Decision 与普通 Luna 均未接受候选时，原 Main 可读取绑定的 **before** 截图，明确审核，再单独继续同一 run／step／job／attempt 和候选。审核本身不点击；续行重新截图并保留窗口身份、目标、几何、可见性、新鲜度、取消与输入检查。已完成输入不重放；原有文字输入结果审核继续使用 **after** 图。

临时命令队列锁竞争会短等后重新检查原续行条件，不再被误记为永久任务绑定失败。取消仍会拒绝，原截止时间和截图后的短派发有效期不会因此延长。Decision／Luna 的阈值、提示词与默认服务均未改动。

新建 API／Agent 环境默认使用 Python 3.12，可保留受支持的已有 Python 3.11 环境。Runtime 与 Amadeus 的虚拟环境、依赖锁继续分开。本地模型路线仍使用 Python 3.11；根目录历史 `pyproject.toml` 描述旧本地／源码依赖，并非独立 API 安装入口。外部视觉 API 无需本地权重或 GPU。接口、模型、密钥环境变量继续分别配置；扩展只接收本机 MCP 连接 token。

此次也同步执行模式维护历史：学习入口已封存移除，共用执行模块和输入门禁保留，不发布新的学习版。详见[封存边界](../LEARNING_PAUSED.md)。
