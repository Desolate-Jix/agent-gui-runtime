# 单界面学习工作台精简设计

## 目标

将面板收敛成一条新用户能够直接理解的主流程：

`学习单个界面 -> 人工修订 -> 加入软件流程 -> 连接多个界面 -> 单步执行验证`

面板不再要求用户理解模板、学习草稿、Trace 页面或 Runtime PathGraph 的内部区别。

## 用户界面

### 左侧导航

学习模式只显示一个入口：`学习工作台`。

以下入口从用户导航隐藏，但底层能力和开发诊断保留：

- 模板展示
- Trace 审计
- 路径图安全验证
- 模板界面 / 学习草稿界面切换

### 学习工作台

学习工作台按阅读顺序包含：

1. 目标窗口绑定与截图。
2. 单界面识别九步进度图。
3. 当前界面的原图、融合框图和识别摘要。
4. 人工修改框、名称、语义、动态内容类型和 Agent 描述。
5. `加入软件流程` 操作。
6. 多界面径向点状图。
7. 当前界面的操作与目标界面连接编辑。
8. 单步 dry-run / Gate 验证。

九步进度图只解释当前单界面的识别过程。径向点状图只表示多个已学习界面之间的操作关系，两者不得混合。

### 多界面点状图

- 圆点代表界面。
- 带文字的连线代表操作和跳转。
- 控件属于界面证据，不成为图节点。
- 当前界面居中，直接相邻界面分布在周围。
- 支持点击、缩放、平移和恢复全图。
- 点击界面后，中间证据和右侧人工编辑同步切换。

## 执行模式

执行模式面向单步操作，不默认展示复杂 Runtime PathGraph。

默认只显示：

- 当前观察界面。
- Agent 选择的下一步。
- 候选目标与定位证据。
- Gate 决策。
- 单步执行与执行后验证。

已学习的多界面流程只作为可折叠的`流程记忆`点状图提供上下文。它不能授权动作。

真实执行继续遵守：

`observe -> Agent -> Gate -> Operation -> Trace -> observe`

## 保留的内部能力

本次只精简可见界面，不删除或放宽：

- Trace 文件、审计 API 和证据链。
- 模板候选与兼容加载路径。
- PathGraph 数据结构与 Runtime 兼容能力。
- Gate、final-submit guard 和危险动作分类。
- Execute Mode 的真实动作验证。
- 回归测试、安全 fixture 和 benchmark 资产。

高级诊断可以按需展示这些内部信息，但默认折叠。

## 状态与错误

- 学习过程中只显示当前步骤、耗时和可操作的错误说明。
- 后台诊断错误写入 Trace，并在高级诊断提供入口。
- 单界面没有融合证据时，不允许显示“可加入流程”。
- 保存、加入流程或连接界面失败时，必须保持当前编辑状态并显示明确错误。
- 多界面流程的迟到加载请求不得覆盖用户最后选择的流程。

## 验证

1. 学习模式左栏只存在`学习工作台`。
2. 页面不存在模板/学习草稿子视图切换。
3. 九步单界面进度图仍能按真实证据推进。
4. 人工修订、保存和加入流程后无需切换页面。
5. 多界面点状图能加载、聚焦、缩放和平移。
6. 点击界面节点会切换对应带框证据和编辑数据。
7. 执行模式默认不展示复杂 PathGraph，但单步 Gate 流程不变。
8. Trace、模板、PathGraph 和安全 API 仍可被测试与高级诊断调用。

## 非目标

- 不删除底层模板或 PathGraph 文件格式。
- 不重写识别模型和候选生成算法。
- 不让学习产物直接授权点击。
- 不实现自动最终提交、发送、确认或支付。
- 不将 SEEK 规则写入通用学习工作台。
