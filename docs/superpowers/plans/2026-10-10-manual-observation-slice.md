# 显式只读重新观察 / Explicit read-only observation

这是已批准 Adaptive Decision 设计第 7 节的实施细化，不增加执行权限。 / This implements section 7 of the approved Adaptive Decision design without extending input authority.

- 仅 `task_plan.v2` 的已完成原输入、有效证据、当前 `verification_required` 等待可调用 `observe`。保持原 run/step/execution/wait；不执行输入、不请求 API、不自动判定成功或继续。 / Only a v2 verification wait with completed original input and valid evidence permits observe. Keep all original IDs; no input, paid inference, automatic verdict or continuation.
- 请求携带 `observation_request_id` 及当前 `review_packet_sha256`, `evidence_set_sha256`, `assessment_round`。逻辑 ID 在采集前持久占位；同内容重放只读取既有结果，冲突拒绝，未知采集不得重做。 / Persist the logical request and current packet binding before capture; exact retries read back, conflicts fail and unknown captures never repeat.
- 自动与手动追加采集合计每步最多两次，失败或未知尝试也占用次数。手动观察是 Main 显式处理后的新只读请求，拥有最多 12 秒的采集采用期限；不延长、重开或重置自动核验的原 12 秒期限。底层同步截图不能硬中断，晚返回不采用。 / Share a two-attempt cap with automatic capture, counting failed/unknown attempts. A manual request after Main's review has a separate 12-second capture adoption deadline, never resetting the automatic verification deadline. Late synchronous captures are rejected rather than claimed interruptible.
- 自动观察账本已结束后保持原件不变。手动请求与每版审核包另存并在原 backend 锁下比较当前版本后提交。采集中出现取消、目标或证据变化均拒绝采用；未结算采集阻止 review，cancel 仍可用。 / Preserve the finished automatic ledger. Persist manual requests and packet revisions separately and compare the current version under the original backend lock before adoption. Cancellation, target/evidence drift or unsettled capture blocks review; cancellation remains available.
- 新证据使用 `review_packet.v3`：保留原 `after`，追加 `latest_observation`，增加 `packet_revision`、`previous_packet_sha256` 和完整 `packet_ancestors` 链。`assessment_round` 保留最后一次模型评估轮次，不能把手动截图冒充新模型判断。引用原评估时明确它对应旧证据。 / A v3 packet preserves original after and appends latest_observation, revision and ancestry. The assessment round remains that of the last model assessment, whose evidence basis is explicitly retained.
- review 必须绑定当前包和新证据集合；旧版本拒绝。原 `evidence_sha256` 继续绑定动作 after，新证据由集合摘要绑定。review 结算证据包含追加截图和记录；continue 仍需原 wait 显式调用。 / Review binds the current packet and new evidence set; the original after digest remains unchanged. Settlement retains appended evidence and explicit continue still uses the original wait.
- 公共客户端接受可验证的后继审核版本，同版回调去重，新版一次回调；MCP 的 `images=after` 在 observe 响应中返回追加图并标明角色，不伪装成原动作 after。 / Clients accept authenticated successor revisions and deduplicate callbacks by revision. MCP observe image delivery labels the new observation separately from the original action after.

验收 / Checks: 全新合成原回执 → observe → 状态重读/逻辑重放 → 旧审核拒绝 → 新审核结算 → 原 wait continue；加上共享限额、取消/身份漂移、未知占位、关闭/重开读回及公共图像传递。全部离线，不调用真实桌面或付费 API。 / Fresh offline integration plus replay, stale review, limits, cancellation/drift, crash recovery and public image delivery; no real desktop or paid API.
