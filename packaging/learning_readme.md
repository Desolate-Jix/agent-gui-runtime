# Agent Learning Workbench preview / 学习工作台预览

Learning is optional. Execution mode works without this application. This application independently opens and edits a local learning library; teaching capture and workflow execution attach explicitly to a compatible execution installation. / 学习模式可选，执行模式不要求安装本程序。本程序独立打开和编辑本地学习库；采集教学或运行工作流时，明确连接兼容的执行安装。

1. Open `AgentLearningWorkbench.exe`, or use the separately supplied learning Setup. Choose or create a learning data folder outside the installation directory. / 打开 EXE 或使用单独学习安装器；选择或新建安装目录外的学习数据目录。
2. Use Settings → Language for 简体中文 / English. Your language and directory choices are remembered separately. / 在设置的语言菜单切换中英文；语言与目录选择分别记忆。
3. Review/edit/save from Task Steps, Workflow Projects and Interface Library. Graphs refer to exact interface versions. / 在任务步骤、流程项目与独立界面库审核、修改和保存；图引用确切界面版本。
4. For live teaching or execution, install/configure execution mode separately, choose its installation root and an existing session using the same data folder, then explicitly connect. Connection and status reads do not dispatch input. / 实际教学或执行前，单独安装配置执行模式，选择执行安装目录及使用同一数据目录的既有会话，再明确连接；连接和读取状态不执行输入。

For distinguishable learned transitions, the draft proposes local image verification by default. In Task Steps → Result Rules, inspect the original result image, adjust the stable template/search regions and threshold, or disable the option and save. Uncertain matches retain the original request for Agent review; saved disablement remains after reopening. Image matching needs no local neural-model weights. / 可判别的已学跳转默认提议本地图像核验。在任务步骤的结果规则页核对原始结果图，调整稳定模板区域、搜索区域和阈值，也可以关闭后保存。不确定的匹配保留原请求交给 Agent 审核；关闭后保存重开不会自动补回。图像匹配不需要本地神经模型权重。

Current-Agent, delegated and external visual API routes are supported by the execution runtime. Local models are optional and absent from this download. API accuracy and learning cost/speed improvements are not established by this candidate. / 执行运行时支持当前 Agent、委派及外部视觉 API；本地模型可选，下载不含模型。本候选不证明 API 准确率或学习成本、速度收益。

Keep libraries outside application directories. Uninstalling one component preserves the other component and external libraries. Unrecognized or modified installation files are preserved. When an installation retains environments/cache or edited files, verified ownership is retained so Setup can reinstall in the same directory; modified files that collide with the new payload must be reviewed first. / 库放安装目录外；卸载其中一个组件保留另一组件及外部库，未知或修改过的安装文件予以保留。安装目录留有环境、缓存或修改文件时保留核验过的归属，允许同目录重装；与新文件冲突的修改内容须先处理。

This is a preview for trial use. Refer to the corresponding release page for the exact installers, hashes, tested scope and known limitations; source/offscreen checks alone do not prove desktop success. / 这是用于试用的预览版。对应发布页列出确切安装器、哈希、已测范围和已知限制；源码或离屏检查不能替代实机通过。
